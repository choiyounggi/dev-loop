### Considered, not adopted
- platforms-toolchains-regeneration-silently-drops-hand-edited-state — triggers on a generated file that was also hand-edited; D9 forbids the hand edit instead
- qa-document-verification-generated-reference-drift-gates — triggers on a closed-vocabulary reference a model emits tokens from; the r1 copy is a whole-file variant, not a vocabulary
- qa-process-evaluating-review-feedback — its trigger is acting on findings already received; D4 designs the finding itself (its "search for actual usage first" step informed evidence kind (a))
- backend-common-change-impact-compiler-as-call-site-inventory — triggers on changing an existing contract's signature, not on judging whether a new element is needed
- qa-process-scope-purity-checks — gates paths outside an allowed set; lens 1 already covers out-of-scope files, D4 covers in-scope excess
- qa-process-agent-tool-parity-gate — web UI action to tool parity, unrelated to D3/D4
